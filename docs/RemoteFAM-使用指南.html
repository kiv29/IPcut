how it works

五個步驟，你只做一個。

其他四步，機器人全包。它們各自用一個成熟的開源工具，像生產線一樣一棒接一棒。

你做這個
01📁

丟影片

把原始影片拖進來，跟 Claude 說「幫我剪這支」。這是你唯一要做的事。

02👂

聽寫逐字稿

Whisper 把你講的每個字＋出現的秒數全部記下來，順便找出所有空白。

03🖊️

Claude 決策

Claude 讀完逐字稿，決定剪哪裡、字幕怎麼寫、圖卡放哪，寫成一份script.json。

04🎨

畫面與動畫

Hyperframes 依 script.json 產生字幕、液態玻璃圖卡、臉部推近，再渲染成畫面。

05🎞️

合成匯出

FFmpeg 疊配樂、自動壓低音樂讓人聲當主角，輸出 final.mp4。

the pipeline

一條龍：原始檔 → 成品

同一條流水線，每支影片都走一樣的路。灰色是你，珊瑚色是機器人自動完成。

script.json = 唯一的剪輯決策檔　·　改它就能重剪　·　100% 可重現
the engine

它站在這些開源軟體的肩膀上

系統本身（工作流程、腳本、設計系統）是 Fyn 原創；底層借重幾個世界級的免費開源工具。 安裝時全部自動裝好，你不用懂它們。

🎬

Hyperframes HeyGen · Apache 2.0

HTML 原生影片合成引擎——字幕、液態玻璃圖卡、臉部推近的動畫與渲染都靠它。這套 kit 的畫面來源。

👂

Whisper whisper.cpp · MIT

OpenAI 的語音辨識，本地跑（含中文模型）。把你講的每個字＋時間戳記聽寫下來，字幕與剪點都從這來。

🎞️

FFmpeg LGPL / GPL

影音處理的瑞士刀。負責剪接、降噪、配樂 ducking、壓縮匯出。

✨

GSAP + Chrome 免費商用 · 各自授權

GSAP 讓圖卡 pop 進場、懸浮呼吸；Chrome 是 Hyperframes 逐格出圖的畫布。

＊ 開源引擎由安裝器自動下載、未修改、未內附原始碼；完整授權見 kit 的 CREDITS.md。

install it

三步就好，不用打任何指令

你不需要會寫程式。你只要裝兩個 App，然後對 Claude 講一句話——它會自己把所有東西裝好、逐項驗證。

  • 裝好 Claude Code 和 Google Chrome

    兩個免費 App。Claude Code 是你的剪輯師，Chrome 是它出圖的畫布。

  • 用 Claude Code 打開這個 kit 資料夾

    解壓縮後，在 Claude Code 裡打開 remote-editor-kit 資料夾。

  • 把下面這句話貼給 Claude

    它會執行內建安裝器 setup.sh，自動下載安裝並逐項打勾。中斷了再貼一次會自動續傳。

    貼這句 ✎
    「請幫我安裝這個影片剪輯系統需要的所有環境」
setup.sh 會自動幫你裝好（共 7 項，約 10–20 分鐘、下載約 2GB）：
  • Homebrew ／ 套件管家
  • Node.js ／ 引擎執行環境
  • FFmpeg ／ 影音處理（含字幕引擎）
  • Whisper ＋ 中文模型 ／ 語音辨識 1.5GB
  • 降噪模型 cb.rnnn ／ 去背景噪音
  • Google Chrome ／ 若尚未安裝
  • Hyperframes ＋ 相依套件 ／ 渲染引擎

系統需求：macOS（Apple Silicon 或 Intel）· 硬碟 ≥ 5GB · 記憶體建議 ≥ 16GB · 安裝過程需連網、可能要輸入一次 Mac 密碼（安裝軟體的正常流程）。

start editing

裝好之後，怎麼用

📥

1 · 丟影片

把影片檔拖進 kit 資料夾（或直接拖進 Claude 對話）。

💬

2 · 說一句話

跟 Claude 說 「幫我剪這支影片」。想要什麼風格、重點，直接用講的。

👀

3 · 每一階段看畫面確認

Claude 會一步步帶你走，每個階段給你看畫面；不喜歡就說，它重做。

📤

4 · 拿成品

成品在 out/final.mp4（高畫質）＋ out/reel_web.mp4（上傳版）。

要重剪？
改一下 script.json（或直接跟 Claude 說要改哪裡），重跑就好——一切可重現。
🎞️

加分功能 · AI 生成 B-roll 選配 · 需自備 Higgsfield 額度

沒有畫面素材也不怕。接上 Higgsfield，Claude 會從你的台詞挑出有畫面感的時刻， 先把要生成的 prompt 和秒數列給你確認，你點頭才生成、下載、排進影片——蓋住臉的期間字幕自動抬高。 有 Soul 角色的話，生成的人物還能是「你」。

1　claude.ai → Settings → Connectors 連上 Higgsfield MCP 2　說「幫我生成一段咖啡廳工作的 B-roll」

＊ 完全選配。沒接 Higgsfield，其他功能照常；也能直接放自備素材當 B-roll。

the rules

幾條讓成品穩定的鐵律

字幕永遠不擋臉

字幕帶固定在下巴以下、胸口位置；圖卡放字幕帶下方或頂部安全區。

一個決策檔

script.json 是唯一真相：剪點、字幕、圖卡都在裡面，改它＝重剪，完全可重現。

別手改 hf/ 資料夾

那是自動產生的；要改就改 script.json，重跑會重生。

配樂用你有授權的音樂

系統會自動 ducking 讓人聲當主角，但音樂版權要自己確認。

換品牌只改一個檔

顏色/字型在 templates/design-tokens.css，或選內建風格（見 STYLES.md）。

一份授權一人

成品 100% 歸你；系統本身禁止轉售、散布。詳見 LICENSE.md。
