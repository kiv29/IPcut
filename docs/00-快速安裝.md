# 快速安裝（貼一句話就好）

1. 安裝 [Claude Code](https://claude.com/claude-code) 和 [Google Chrome](https://www.google.com/chrome/)
2. 用 Claude Code 打開這個 kit 資料夾
3. 貼這句話給 Claude：

> **請幫我安裝這個影片剪輯系統需要的所有環境**

Claude 會執行 kit 內建的安裝器（`setup.sh`），自動下載並安裝：
Homebrew、Node.js、FFmpeg、whisper 語音辨識＋中文模型（約 1.5GB，要等幾分鐘）、
Google Chrome（如果沒有）、**Hyperframes 渲染引擎**（HeyGen 免費開源）、kit 本身的依賴。
裝完會自動逐項驗證，全部打勾才會告訴你「可以開始了」。

- 過程中系統可能要你輸入一次 Mac 密碼（安裝軟體的正常流程）
- 中斷了沒關係，再跑一次會自動續傳、已裝好的自動跳過

## 系統需求

- macOS（Apple Silicon 或 Intel）
- 硬碟空間 ≥ 5GB、記憶體建議 ≥ 16GB
- 網路（安裝時下載工具與模型）

## 裝好之後

把你的影片檔丟進 kit 資料夾（或直接拖進 Claude Code 對話），說：

> **幫我剪這支影片**

後面的事 Claude 會一步一步帶你。
