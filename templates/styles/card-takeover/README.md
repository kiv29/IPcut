# 卡片收合 Card Takeover  `card-takeover`

![preview](preview.mp4)

**長相**：把人物去背塞進圓角卡片、頭頂衝出卡緣；襯線宋體標題＋珊瑚 #C9694A 白卡＋逐幀臉部追蹤。片段在全螢幕與卡片間切換。Fyn 本人也在用的第二套。

**什麼時候用**：想要精緻、雜誌感、有「產品開箱／系統展示」氛圍。需要去背（本地 Vision 免費）。

**設計 tokens**：主色 珊瑚 #C9694A／米白卡 #FFFDF8／襯線 Noto Serif TC；字幕卡片模式深色 on-light。

**Hero 動態圖卡**：去背卡片版型見 remote-editor skill 的 card 模式；設計源＝範例 fyn-weekend-08。

## 怎麼用
在專案 `script.json` 加一行 `"style":"card-takeover"`，或跟 AI 說「用卡片收合風格剪」。
引擎會自動把 `tokens.css` 套到字幕與動態圖卡。
