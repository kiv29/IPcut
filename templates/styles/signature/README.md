# 招牌金字幕 Signature Gold  `signature`

![preview](preview.mp4)

**長相**：Fyn 最常用的招牌look。白字繁中＋多層黑描邊、關鍵字金色 #F4C430、亮黃貼片；液態玻璃圖卡＋金色 count-up 數字。字幕帶 bottom:630 永不擋臉。

**什麼時候用**：一般口播乾貨、教學、日常分享——最百搭、最安全、全自動。

**設計 tokens**：主色 金 #F4C430／黃貼片 #FFD23F；字幕白 42px；液態玻璃 rgba(255,255,255,.16)+blur16。

**Hero 動態圖卡**：純字幕/圖卡疊加，無 hero 專屬 MG（用內建 statCounter/glassCard/stamp 等）。

## 怎麼用
在專案 `script.json` 加一行 `"style":"signature"`，或跟 AI 說「用招牌金字幕風格剪」。
引擎會自動把 `tokens.css` 套到字幕與動態圖卡。
